MiriBloom Admin Orders Dashboard

1. Run ADMIN_DASHBOARD_POLICIES.sql in Supabase SQL Editor.
2. Upload to the ROOT of the GitHub miribloom repository:
   - admin.html
   - admin.js
   - admin.css
   - supabase.js if it is not already present
3. Commit changes.
4. Log into the MiriBloom account you added to admin_users.
5. Open:
   https://miribloom.com/admin.html

Regular customers who are not listed in admin_users will see Access denied.

Dashboard features:
- Total/New/Preparing/Shipped counts
- View all paid orders
- Update fulfillment status
- Open each customer's Beauty Profile
- Filter orders by fulfillment status
